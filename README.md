# BDB-Labs Homebrew Tap

This tap publishes the AIRA CLI for Homebrew.

## Install

```bash
brew install BDB-Labs/aira-scanner/aira
```

Or tap once and use the short name:

```bash
brew tap BDB-Labs/aira-scanner
brew install aira
```
