# BDBLabs Homebrew Tap

This tap publishes the AIRA CLI for Homebrew.

## Install

```bash
brew install BDBLabs/aira-scanner/aira
```

Or tap once and use the short name:

```bash
brew tap BDBLabs/aira-scanner
brew install aira
```
